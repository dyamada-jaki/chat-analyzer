# UC-001: リアルタイム感情分析

## 📋 基本情報
- **ID**: UC-001
- **優先度**: High
- **ステータス**: ✅ 実装済み
- **関連機能**: Chrome拡張機能、Gemini AI統合

## 👤 ユーザーストーリー
**As a** チームメンバー  
**I want to** 投稿されたメッセージの感情を自動で分析してもらいたい  
**So that** チーム内の雰囲気やコミュニケーションの質をリアルタイムで把握できる

## 🎯 受け入れ基準
- [ ] 新しいメッセージが投稿されると3秒以内に感情分析が完了する
- [ ] 感情アイコン（😊😢😠😐）がメッセージの横に表示される
- [ ] Gemini APIエラー時はフォールバック分析が動作する
- [ ] 分析結果がバックエンドに保存される

## 📝 詳細シナリオ

### 正常フロー
1. **前提条件**
   - Chrome拡張機能がインストール済み
   - Google Chatページを開いている
   - バックエンドサーバーが起動中（http://localhost:3001）

2. **メインフロー**
   ```
   ユーザー: メッセージを投稿
   ↓
   拡張機能: DOMの変更を検知（MutationObserver）
   ↓
   拡張機能: メッセージテキストを抽出
   ↓
   拡張機能: バックエンドAPIに分析リクエスト送信
   ↓
   バックエンド: Gemini AIで感情分析実行
   ↓
   バックエンド: 分析結果を返却
   ↓
   拡張機能: 感情アイコンをDOMに挿入
   ```

3. **期待結果**
   - メッセージの右側に適切な感情アイコンが表示される
   - アイコンにホバーすると詳細情報が表示される

### 例外フロー
- **Gemini APIエラー**: シンプルなキーワードベース分析にフォールバック
- **ネットワークエラー**: ローカルでの基本分析を実行
- **DOM構造変更**: セレクター更新で対応

## 🧪 テストケース
1. **正常系**: 各感情タイプのメッセージで正しいアイコンが表示される
2. **異常系**: APIエラー時にフォールバック分析が動作する
3. **パフォーマンス**: 100件の連続メッセージで性能劣化しない
4. **UI**: アイコンがメッセージレイアウトを崩さない

## 📊 成功指標
- **精度**: 手動評価で80%以上の感情分析精度
- **速度**: メッセージ投稿から表示まで平均2秒以内
- **安定性**: 8時間連続使用でエラー率5%未満
